# 🏠 EstatePro — Real Estate Intelligence Platform

EstatePro is a full-stack real estate intelligence platform designed to help users manage properties, analyze investments, and understand real estate market trends through a modern web interface.

## 🚀 Live Demo

**Frontend:**
https://real-estate-analyzer-fronten.onrender.com

**Backend API:**
https://real-estate-analyzer-1-aoph.onrender.com

---

## ✨ Features

* 📊 Professional real estate dashboard
* 🏠 Property listing and management
* ➕ Add new properties
* 🗑️ Delete properties
* 🔍 Property search and analysis
* 📈 Investment and rental analysis
* 💰 Property price and rental calculations
* 📊 Market insights
* 👤 User management
* ⚙️ Settings
* 🤖 AI-powered property intelligence
* 🌐 Live frontend and backend deployment

## 📊 Property Intelligence

EstatePro provides useful real estate metrics including:

* Property price
* Price per square foot
* Monthly rent
* Annual rent
* Rental yield
* ROI
* Investment score
* Property type
* Location
* Area and size

These insights help users make more informed property investment decisions.

---

## 🌐 Deployment

The application is deployed as separate frontend and backend services.

**Frontend:** React + Vite on Render
**Backend:** Django + Gunicorn on Render
**Repository:** GitHub

The React frontend communicates with the deployed Django backend through API endpoints.
